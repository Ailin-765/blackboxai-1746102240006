# Juego 3D Virus Zombie

## Project Overview
Juego 3D Virus Zombie is an interactive 3D game built using Three.js where players embark on a thrilling adventure to solve puzzles, navigate mazes, and confront a final boss. The game immerses players in a rich environment where they can learn about microscope parts while avoiding the dangers posed by a zombie scientist.

## Installation
To get started with the Juego 3D Virus Zombie, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/juego-3d-virus-zombie.git
   cd juego-3d-virus-zombie
   ```

2. **Open the HTML file:**
   Open `index.html` in your web browser to play the game. There is no additional server setup required as the game runs entirely in the browser.

## Usage
Once you have the game open in your browser:

1. You will see a welcome screen with a button to start the game.
2. Click the "Comenzar" button to initiate the puzzle phase.
3. Follow the on-screen instructions to solve puzzles, navigate through mazes, and defeat the boss.
4. Use the arrow keys or `WASD` to control the player throughout the maze.

## Features
- **3D Graphics:** Utilizes Three.js to render 3D game environments and objects.
- **Interactive Gameplay:** Solve puzzles, navigate mazes, and engage in a boss fight.
- **Simple Controls:** Intuitive keyboard controls for movement and game interactions.
- **Responsive UI:** Dynamic game overlays to convey information and instructions.

## Dependencies
The game relies on the following libraries, as specified in the HTML and JavaScript files:
- **Three.js:** [Three.js library](https://threejs.org/)
- **Tailwind CSS:** For styling (included via CDN)
- **Font Awesome:** For icons (included via CDN)

You don’t need to install these dependencies manually since they are loaded from CDN links present in `index.html`.

## Project Structure
The project consists of the following files:

```
/juego-3d-virus-zombie
│
├── index.html          # The main HTML file containing game UI
└── main.js            # The JavaScript file implementing game logic and Three.js
```

### File Descriptions
- **index.html:** Contains the HTML structure, linking styles and scripts necessary for rendering the game and managing user interactions.
- **main.js:** Handles the game logic including initialization, game state management, user controls, and rendering of 3D graphics.

## Conclusion
Enjoy delving into the world of Juego 3D Virus Zombie! Experiment with the game mechanics, and feel free to contribute ideas or improvements. Happy gaming!
